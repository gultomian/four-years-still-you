# Four Years, Still You ♡

A small anniversary website with a Polaroid-style photo gallery.

## Preview locally
1. Extract the ZIP.
2. Open the `four-years-still-you` folder.
3. Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository named `four-years-still-you`.
2. For the simplest free GitHub Pages setup, choose **Public**.
3. Upload **the contents of this folder** (the `index.html`, `README.md`, and `photos` folder) to the repository root. Do not upload the outer folder itself.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes. GitHub will show your site URL, usually:
   `https://YOUR-USERNAME.github.io/four-years-still-you/`

## Privacy
A GitHub Pages website is public to anyone with its URL, and a public repository also exposes the source files and photos. Avoid uploading anything you want to keep private.
